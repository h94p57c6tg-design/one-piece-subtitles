New: Watch in Browser opens a built-in video player and requests its English SRT automatically. This avoids iPhone-only app links on laptops. Video comes from Pixeldrain; captions come from your GitHub SRT or DubTitlerr. The browser needs internet. Playback depends on the video host allowing your browser to stream it.

💻 Laptop · Firefox / Chrome

Watch in Browser for inline playback, or choose VLC Desktop + SRT under any episode to download a tiny VLC playlist. Open it with VLC on Mac/Windows/Linux.

📺 Chromecast

Open this hub in Chrome on your laptop, start the video, then use Chrome's Cast → Sources → Cast screen option to mirror video and captions. Direct receiver casting is not built in.

🔥 Fire TV

Open this hub's published web address in Amazon Silk and click Watch in Browser. The remote can navigate buttons. Video-host restrictions or TV browser codecs may block it.

📱 iPhone / iPad

Open the published website in Safari or Firefox for browser playback; for native full-screen captions, Infuse remains your tested fallback.

💻 NEW: VLC on Windows / Mac / Linux

Choose an episode, then click VLC Desktop + SRT. Your browser saves a tiny .m3u playlist containing the streaming video address and a request for VLC to load that episode’s SRT. Open the downloaded .m3u file in the VLC desktop application. The episode itself is streamed, not downloaded.

If VLC plays the video without subtitles: some desktop VLC versions cannot read a remote HTTPS SRT directly. Click the episode’s Matching SRT button, save the .srt file on your computer, and choose VLC → Subtitle → Add Subtitle File while the stream is playing. For Mac, the menu is in the top system menu bar. The source SRTs are small files, not episode downloads.

Important: the desktop VLC button creates a playlist download; ordinary browsers cannot automatically launch VLC without an installed protocol handler or file association. If the .m3u opens as text, right-click or choose Open With → VLC. The automatic subtitle feature is best effort until tested on your VLC version.

One-time setup for your TV

For Fire TV you need a normal HTTPS website address, not an HTML file stored in your laptop. Once this GitHub repository is published with GitHub Pages, the same URL can be opened on your phone, laptop and Fire TV. To enable Pages: repository Settings → Pages → Deploy from a branch → main / (root) → Save. Check the Pages screen for the confirmed live address.

For Chromecast, mirror your Chrome desktop or Chrome tab rather than relying on receiver-native subtitle support. Mirroring the screen is the safer way to keep our caption overlay visible; your computer needs to remain on.

The player doesn't redistribute or download episode files. The streaming service may block cross-site viewing. If this happens, use the existing Infuse or other native playback method instead.

Caption or video not working? Read this.

Video playback is requested from Pixeldrain; some browsers, TVs or embed settings may reject it. The Try alternate video host button switches between pixeldrain.net and pixeldrain.com. This does not bypass any access restrictions.

Caption files are requested from GitHub. If the browser blocks the file or if an SRT is missing, you can manually choose an SRT you already have: .

If the subtitles do not match, especially Muhn Pace, use the caption shift controls. A single offset cannot always repair edits that differ across the episode.

On mobile, full-screen behavior varies. Try Use native CC if captions disappear in native full-screen; use the in-page browser player as another option.
